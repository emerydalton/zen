# Contributing to /zen

Thanks for your interest in /zen. It is at an early stage, so the most valuable contributions right now are ideas, feedback, and small focused changes.

## Ways to contribute

- **Ideas and questions** — open an issue and describe the problem first.
- **Bug reports** — open an issue with the *Bug report* template if something in the docs is wrong.
- **Docs** — fixes and additions under `docs/` are always welcome.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change.
3. Open the pull request and fill in the template.

## Commit messages

Use short, imperative subject lines, with detail in the body when it helps.
