# Contributing to /zen

Thanks for your interest in /zen. The language is at an early stage, so the most valuable contributions right now are ideas, feedback, and small focused changes.

## Ways to contribute

- **Language proposals** — open an issue with the *Language proposal* template. Describe the problem first, then the proposed design.
- **Bug reports** — open an issue with the *Bug report* template and include a minimal reproduction.
- **Docs and examples** — fixes and additions under `docs/`, `spec/`, and `examples/` are always welcome.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change.
3. Add or update tests under `tests/` when behaviour changes.
4. Update `spec/` and `CHANGELOG.md` when the language itself changes.
5. Open the pull request and fill in the template.

## Commit messages

Use short, imperative subject lines (for example, `Add lexer for numeric literals`), with detail in the body when it helps.
