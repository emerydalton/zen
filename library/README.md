# Library

This is where outside documents wait.

The library is outside the loop, like the wiki. A stretch reads all of
`docs/`. It does not have to read anything here, and nothing here is a
rule of /zen.

## What is in it

- `waiting/` holds documents that have been brought in and not yet
  read in a loop. Each one is kept exactly as it arrived.

There is nothing else yet. A place for documents that have been read
is made when the first one has been read, and not before.

## What happens to a document

A document waits here until a stretch reads it next to the repository.
What is seen then goes in a note in `docs/`. The document stays outside
`docs/`.
