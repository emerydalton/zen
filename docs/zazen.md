# /zazen

Written on 2026-11-13, after it-has-to-serve.md.

## The rule

A /zazen is the unit between one o7 and another.

The author's words: "let /zazen be the unit between one o7 and another,
the preceding or following. Smallest /zazen is 1 /zen loop carried through
beginning to end. Largest would be unfathomably large, perhaps infinite."

## The long way

/zen is the way of working. A /zazen is a unit of it. The README used to
say "from o7 to o7 is /zen", which gave the practice and its unit the same
name. They now have one name each.

A /zazen is measured from an o7. It can be counted to the o7 before or to
the o7 after.

It has a smallest size. The smallest /zazen is one /zen loop, carried
through from beginning to end.

It has no largest size that anyone can name. The author said the largest
would be unfathomably large, and perhaps infinite.

The older notes say "session", "loop" and "stretch" for the same span. By
"start in the middle" in three-names.md, they are left as they are. From
now on the word is /zazen.

## What could not be told

Three things, each kept here with its place.

- At "1 /zen loop". The README draws the loop with more than one o7 in it:
  o7, /zendoc, o7, /zen, o7. The reader could not tell whether one /zen
  loop is the span between two neighbouring o7s, or one whole turn of that
  drawing.
- At "unfathomably large". If a /zazen always ends at the next o7, it is
  large only when a great deal happens before that o7. If it can run to
  any later o7, it can hold other /zazen inside it. The reader could not
  tell which. loose-ends.md says a run of /zazen is a sesshin, and the
  second reading would make a sesshin a /zazen too.
- At the README's "three words". /zazen begins with a slash like /zen and
  /zendoc. The author called it a unit. Nobody has said whether it is a
  fourth word to be said, or only a name.

## How this was learned

ford.md and it-has-to-serve.md already used the word, and loose-ends.md
said it had no note.

A reader who had not seen that evening read the repository and reported
that the README still gave the span from o7 to o7 the name /zen. The
author quoted that line back, "still says that span is /zen", and then
gave the definition above in one message.

The same reader had earlier repeated the README's line as if it were
settled. It was the README that was behind, and it was changed in the
same commit as this note.
