# Three names

Written on 2026-11-13, in the stretch after in-light-of.md.

## The rule

Three things this loop already does now have names. The names are borrowed
from Lion Kimbro's notebook system, which in-light-of.md describes. Nothing
about the practice changes. Only the names are new.

## Late binding

Do not fix a thing ahead of time. Fix it when you actually run into it.

This was already here. The README says that if a /zendoc comes back wrong,
the docs were unclear, and the next /zen fixes them. the-wiki.md found
three out-of-date wiki pages and left them in place.

## The title is a contract

A note holds what its title names, and nothing else. Anything else written
in it will not be found again, because nobody will look for it there.

This was already here. Every note in docs/ has one title and one rule. The
name adds one thing: when the writing leaves the title, that is the moment
to start another note.

## Start in the middle

When a better way is found, use it from now on. Do not go back and redo
the old notes to match.

This was already here. The repository once held the scaffolding of a
programming language. It was removed, the work started again from the
three words, and the changelog kept the history as history.

## How this was learned

The author asked which of Kimbro's ideas could be brought in one for one.
The reader's test was whether the idea already pointed at something that
had happened in the loop. Five passed. These three cost nothing, because
they were already being done. The other two change what a stretch does,
so each has its own note: loose-ends.md and what-goes-where.md.
